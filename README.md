# Óticas Vitales — Site institucional

Site institucional da **Óticas Vitales**, com apresentação da marca, armações, filtros de preferência e caminhos de atendimento.

## Estrutura

- `dist/index.html` — página principal
- `dist/styles.css` — estilos e responsividade
- `dist/script.js` — interações do site
- `dist/assets/` — imagens e identidade visual
- `.openai/hosting.json` — configuração do projeto no ChatGPT Sites

## Executar localmente

Abra `dist/index.html` no navegador ou sirva a pasta `dist` com um servidor estático.
